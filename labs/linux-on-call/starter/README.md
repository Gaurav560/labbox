# Tara Observatory: the server

Tara is a small radio telescope in the hills near Pune: three dishes that listen to the sky every night. This is
your copy of its Linux server, one folder per chapter:

- `01-why-linux` to `04-pipes`: first steps in the terminal (each folder fills up when you open its chapter).
- `05-logs`: the web server's access log and three small log tools (`count_5xx.sh`, `top_ips.sh`, `slowest.sh`).
- `06-finding` to `09-disk-full`: finding things, permissions, processes, and a full disk (`server/`).
- `10-scripts` to `12-environment`: scripts, loops and the environment.
- `13-networking` to `15-capstone`: the observatory's status app, services, and a real on-call night.

Each script says at the top what it should do. Run one with `bash name.sh` (or `./name.sh` once it is executable).
